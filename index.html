Tentang Data Teknologi Panduan

Tentang Proyek

Jelajah-In Progo merupakan proyek WebGIS pariwisata yang menyajikan informasi destinasi wisata Kulon Progo dalam bentuk informasi geografis berbasis web.

Website dokumentasi ini disiapkan untuk menjelaskan tujuan, sumber data, teknologi, dan panduan penggunaan proyek.

Data Pariwisata

Data wisata digunakan sebagai sumber informasi destinasi yang dikelola dalam proyek. Data mencakup atribut destinasi wisata sesuai dengan dataset yang digunakan.

Database proyek disimpan menggunakan Supabase. Rincian atribut dan sumber data dapat dilengkapi sesuai dataset asli.

Teknologi yang Digunakan

  • HTML, CSS, dan JavaScript: membangun tampilan web.
  • WebGIS: menyajikan informasi geografis pariwisata.
  • Supabase: menyimpan dan mengelola database.
  • GitHub: menyimpan kode dan dokumentasi proyek.
  • GitHub Pages: menerbitkan website dokumentasi.

Panduan Penggunaan

  1. Buka halaman WebGIS untuk melihat informasi wisata.
  2. Jelajahi peta dan informasi destinasi yang tersedia.
  3. Gunakan dokumentasi ini untuk memahami proyek dan datanya.

Catatan: tautan WebGIS akan ditambahkan setelah alamat publiknya dikonfirmasi.
